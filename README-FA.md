# رزآپلود سنتر

نسخه شروع یک آپلودسنتر فارسی و راست‌چین با Node.js و Express. این نسخه برای اجرای محلی و آزمایش ساخته شده است.

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر
- اینترنت برای نصب بسته‌ها و بارگیری Tailwind CDN در صفحه

## اجرا در ویندوز (CMD)
1. ZIP را استخراج کن و وارد پوشه‌ای شو که `package.json` در آن است.
2. فایل `.env.example` را به `.env` کپی کن:
   ```bat
   copy .env.example .env
   ```
3. فایل `.env` را با Notepad باز کن و `SESSION_SECRET` را به یک رشته تصادفی طولانی (حداقل ۳۲ کاراکتر) تغییر بده.
4. نصب:
   ```bat
   npm.cmd install
   ```
5. اجرا:
   ```bat
   npm.cmd start
   ```
6. در مرورگر باز کن: `http://localhost:3000`

## امکانات نسخه شروع
- ثبت‌نام و ورود با ایمیل و رمز عبور هش‌شده
- آپلود چند فایل، نوار پیشرفت، فهرست فایل‌ها و حذف فایل
- لینک دانلود مستقیم و صفحه اشتراک‌گذاری
- سهمیه پیش‌فرض حساب ۱۰ گیگابایت؛ سقف پیش‌فرض هر فایل ۱ گیگابایت
- اطلاعات حساب و فایل‌ها در `data/database.json` و بایت‌های فایل در `storage/`

## محدودیت مهم
این پروژه نسخه آزمایشی محلی است، نه سرویس آماده انتشار عمومی. نشست‌ها در حافظه نگه‌داری می‌شوند و با خاموش شدن سرور پاک می‌شوند؛ فایل‌های JSON نیز برای بار هم‌زمان بالا و استفاده چندفرآیندی مناسب نیستند. پیش از انتشار عمومی باید ذخیره‌سازی پایدار نشست‌ها، پایگاه‌داده مناسب، HTTPS، پشتیبان‌گیری، محدودیت‌های سوءاستفاده و تنظیمات امنیتی استقرار اضافه شوند. آپلود از URL عمداً غیرفعال است.
